# 全国ドーミーインスタンプラリー ベンチマーク調査

調査日: 2026-08-03 / 調査手段: Web検索（各サービスの公開情報）

## 0. 結論

- **「ドーミーインの訪問記録を自分でつけられるWebサービス」は、現時点で見当たらない。** 存在するのは (1) 公式の会員プログラム（Dormy's）と (2) 個人ブログの宿泊レポート、の2種類だけで、その中間にある「ユーザー自身が制覇率を管理するツール」は空白。
- 一方で、**同型サービス（施設めぐり記録）は他ジャンルでは完全に確立**している（道の駅・城・寺社・サウナ・博物館）。UI/ゲーミフィケーションの手本はそこから丸ごと借りられる。
- 水族館版（約180施設）に対し、ドーミーインは**系列全体でも約80〜90施設**。母数が小さいぶん「制覇が現実的」＝モチベーションは高いが、**一覧だけでは薄い**。ドーミーイン固有の軸（大浴場・サウナ・夜鳴きそば・ご当地朝食・ブランド）でコンテンツ量を補うのが成否の分かれ目。

**読み取れること**

1. 「ドーミーイン全国制覇」という欲求は**すでにブログ側に顕在化している**（制覇率を自分でカウントして公開している人がいる＝需要の証明）。
2. しかしそれを**支えるツールが存在しない**ので、みんな手作業（ブログ表・Googleマイマップ・Excel）でやっている。ここが刺さりどころ。
3. 唯一の実質的な競合はサウナイキタイ。ただし目的が「サウナ」なのでブランド横断の制覇管理はできず、共存可能（むしろ導線として使える）。

## 4. デジタルスタンプラリーSaaS（公式コラボになった場合の選択肢）

- [furari](https://furari.jp/) — GPS（みちびき対応）／QR／NFC／キーワード、地図・特典・不正防止・分析まで標準、WEB＋アプリ同時開催
- [てくてくスタンプ](https://www.tektekstamp.jp/) — アプリ不要のWeb型、4か所・1週間以内なら無料、最短15分で公開
- [プラチナラリー](https://stamprally.digital/) — 音声AI判定＋GPS連動
- 比較まとめ: [デジスタNavi（25社調査）](https://www.digista-navi.com/list/)

> これらは**期間限定キャンペーン向け**。「一生モノの訪問記録」を蓄積する用途には向かないので、自前実装（＝水族館版の横展開）で正しい。ただし公式とのタイアップ提案時には「既製SaaSではなく常設の記録サービスである」ことが差別化の説明になる。

## 5. 空白地帯の整理（なぜ狙えるか）

```
                記録できる（ツール）
                      ▲
  サウナイキタイ ●     │     ● 攻城団 / ホトカミ / 道の駅めぐり
  （サウナ軸）         │       （ジャンル特化・UGC）
                      │
  ────────────────────┼──────────────────── ブランド特化
                      │  ★ 全国ドーミーインスタンプラリー（空白）
  楽天GORA ●          │
  （予約×制覇）        │     ● ドミ活 / dormyinn Walker / 制覇率40%ブログ
                      ▼       （読み物のみ）
                読めるだけ（コンテンツ）
```

- 縦軸「記録ツールか読み物か」× 横軸「ジャンル横断かブランド特化か」で見ると、**ブランド特化 × 記録ツール**の象限が空いている。
- 一般に「単一ブランドの全店制覇」は母数が小さく事業化しづらいためツールが生まれにくいが、ドーミーインは例外的に条件が揃っている:
  - 施設ごとに**大浴場名・泉質・朝食が違う**（＝コレクション性がある）
  - **熱狂的ファン層（ドミ活）が既にいる**
  - **サウナ／温泉ブームと接続**している
  - 全国に散っていて**旅の目的になり得る**

## 6. 水族館版からの差分設計（実装メモ）

既存 `aquarium-log` の構造はほぼそのまま流用可能。置き換えるのは「施設マスタ」と「属性軸」。

| 水族館版 | ドーミーイン版への翻案 |
|---|---|
| 施設マスタ `aquariums_list.csv`（約180館） | ドーミーイン系列マスタ（約80〜90施設）※ブランド列を持つ: ドーミーイン / PREMIUM / EXPRESS / 御宿 野乃 / GLOBAL CABIN |
| 生き物フィルター（ペンギン・シャチ…） | **設備・体験フィルター**: 天然温泉 / 露天風呂 / サウナ / 水風呂 / 外気浴 / 夜鳴きそば / ご当地朝食 / 無料アイス / 漫画コーナー / ランドリー |
| 「集めた魚種印」図鑑 | **「集めた湯印」**（大浴場名＋泉質のコレクション）、**ご当地朝食コレクション**、**夜鳴きそば杯数カウンター** |
| 都道府県別 達成率＋塗りつぶし地図 | そのまま（本カテゴリの標準UI。道の駅系・GORAも同型） |
| 達成バッジ（10/30/50/100館） | 施設数が少ないので刻みを変更（5 / 10 / 25 / 50 / 全店制覇）＋ブランド別制覇バッジ（例「野乃制覇」） |
| ミッション | 「北海道のドーミーイン全制覇」「天然温泉のある館を10館」「サウナ室90℃以上を5館」など |
| 訪問回数 | ホテルは**リピートが前提**なので、水族館以上に「泊数」の価値が高い。累計泊数・連泊記録を前面に |

**ドーミーイン版で追加を検討したい軸**（他サービスから借りるなら）

- サウナイキタイ流の**スペック検索**（サウナ室温度・水風呂温度・外気浴の有無）
- 楽天GORA流の**制覇数ランキング**（全国／都道府県別）— ただし個人情報の扱いに注意
- 銭湯お遍路流の**全店制覇者の殿堂ページ**
- 攻城団／ホトカミ流の**ユーザーからの情報提供**（朝食メニュー・湯の写真）で運営のデータ更新負荷を下げる

## 7. リスク・注意点

1. **商標**: 「ドーミーイン」「Dormy」は共立メンテナンスの商標。ロゴ・館内写真の無断使用は避け、全ページに「本サイトは非公式のファンサイトです」を明記する。サイト名にブランド名を含めるのは記述的使用の範囲に留める（例: `全国ドーミーインスタンプラリー（非公式）`）。
2. **公式スタンプとの混同**: Dormy's公式にも「スタンプカード」があるため、「公式のポイント／スタンプとは無関係」の注意書きが必須。問い合わせが公式に流れるとトラブルになる。
3. **データ鮮度**: 新棟オープン・改装・閉館が水族館より頻繁（[公式の新棟オープン情報](https://dormy-hotels.com/dormyinn/information/shinken12/)）。施設数も出典によって差がある（85店とする[集計](https://locationsdb.com/ja/brands/dormy-inn)、系列5ブランドで約90施設とする集計）ため、**公開前に公式サイトから一次データを取り直す**こと。
4. **母数の小ささ**: 約90施設は「全制覇された後」が早く来る。制覇後の遊び（再訪記録・泊数・季節メニュー・年度ごとのリセット）を最初から設計しておく。

## 8. 次アクション（提案）

1. 公式サイトから系列全施設の一次データを取得し、`dormyinn_list.csv`（ブランド／大浴場名／泉質／サウナ有無／朝食名物／緯度経度）を作成。
2. 水族館版のフィルタ定義（生き物）を設備・体験軸に差し替えて横展開。
3. 差別化の目玉を1つに絞る。おすすめは**「湯印コレクション」**（各館の大浴場名を集める図鑑）— ドーミーイン特有で、他のどのサービスにも存在しない。
4. 中期的には、楽天GORAの事例を根拠に共立メンテナンスへの公式タイアップ提案も検討可能。
