📷 写真をまとめて追加

水族館を選んで写真を選びます。写真は選ぶたびに追加されていくので、 同じ水族館なら何回に分けて選んでも構いません。
別の水族館ぶんも一緒に追加したいときは「＋ 水族館を追加」で行を増やしてください。
JPEG / PNG / WebP・1枚5MBまで。
